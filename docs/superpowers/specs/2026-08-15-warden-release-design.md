# Warden Release Workflow Spec

## Overview
Hybrid release workflow for Warden:
- **Artifacts**: Standalone binaries + portable archives.
- **Auto-updates**: `pyupdater` for delta patches + version checks.
- **Hosting**: GitHub Releases (artifacts) + GitHub Pages (`versions.json`).
- **CI/CD**: GitHub Actions automates builds, releases, and updates.

---

## Artifacts
| Platform  | Standalone Binary       | Portable Archive               |
|-----------|-------------------------|---------------------------------|
| Windows   | `Warden.exe`            | `Warden-windows-vX.Y.Z.zip`     |
| macOS     | `Warden.app`            | `Warden-macos-vX.Y.Z.tar.gz`    |
| Linux     | `Warden`                | `Warden-linux-vX.Y.Z.tar.gz`    |

- **Update metadata**: `versions.json` (hosted on GitHub Pages).
- **Delta patches**: Generated by `pyupdater` for auto-updates.

---

## Versioning
- **Format**: `X.Y.Z+build.<CI_BUILD_NUMBER>` (e.g., `1.0.0+build.42`).
- **Source**: GitHub Actions `github.run_number`.
- **Tagging**: GitHub Actions creates a tag (`vX.Y.Z+build.<CI_BUILD_NUMBER>`) on release.

---

## Workflow
### Build Phase
1. **Trigger**: Push to `main` or manual workflow dispatch.
2. **Setup**:
   - Install Python dependencies (`pip install -r requirements.txt`).
   - Install PyInstaller (`pip install pyinstaller`).
   - Install `pyupdater` (`pip install pyupdater`).
3. **Build Binaries**:
   - Run `scripts/build.py` to generate platform-specific binaries.
4. **Package Archives**:
   - Zip binaries into platform-specific archives.
5. **Generate Update Metadata**:
   - Use `pyupdater` to generate delta patches and `versions.json`.

### Release Phase
1. **Create GitHub Release**:
   - GitHub Actions creates a release on tag push (`v*`).
   - Attach standalone binaries + portable archives to the release.
2. **Publish Update Metadata**:
   - Upload `versions.json` and delta patches to GitHub Pages.
3. **Auto-Update Workflow**:
   - Separate GitHub Actions workflow to generate/update `versions.json` and delta patches.
   - Triggered on release creation or manual dispatch.

### Update Mechanism
- **Library**: `pyupdater` (cross-platform).
- **Flow**:
  1. App checks `versions.json` on startup.
  2. If update available, download delta patch (or full binary if no patch).
  3. Apply update and restart.
- **Hosting**: GitHub Releases (binaries) + GitHub Pages (`versions.json`).

---

## GitHub Actions
### Workflows
1. **`release.yml`**:
   - **Triggers**: Push to `main`, manual dispatch, or tag push (`v*`).
   - **Jobs**:
     - **Build**: Generate binaries + archives.
     - **Release**: Create GitHub Release, attach artifacts.
2. **`update.yml`**:
   - **Triggers**: Release creation or manual dispatch.
   - **Jobs**:
     - **Update Metadata**: Generate `versions.json` and delta patches.
     - **Publish**: Upload `versions.json` to GitHub Pages.

### Matrix
- **Platforms**: Windows, macOS, Linux.
- **Python Version**: 3.10+.
